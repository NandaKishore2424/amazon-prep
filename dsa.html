DSA practice sheet

Topic by topic, in the order to learn them. Each topic opens with what to understand before you start solving — the concepts and patterns — then a tiered problem list. Problems marked ★ asked appear in the interview experiences collected on this site, so they carry more weight than the rest.

How to use this sheet

  • Filter to ★ asked first. That is — problems that real candidates were really given. Do those before anything else — especially when time is short.
  • Then the Core tier of Arrays, Hashing, Binary Search, Trees and DP. Skip Warm-up if a topic is already comfortable.
  • For DP, do the ladder, not the volume. Take House Robber and Coin Change and write all four versions — recursion, memo, tabulation, space-optimised. One problem done four ways beats four problems done once, because that is literally what the Feb 2026 interviewer walked the candidate through.
  • Write at least five solutions by hand on paper. In-person rounds are frequently whiteboard, and one corpus experience says so explicitly.
  • Say the time and space complexity out loud every single time. Every experience that lists tips mentions it.
